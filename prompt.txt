## The 3 Stages of Git

When you are working in your project folder, you are interacting with three different areas:

### 1. `git add .` (The Staging Area)

* **What it means:** "Gather files and put them in the staging box."
* **How it knows about `main.c`:** Git is constantly monitoring your project folder (called your **Working Directory**). The moment you save `main.c` inside that folder, Git notices that a new file appeared or an old one changed. When you type `git add .`, the dot `.` means "everything." Git takes a snapshot of your `main.c` file and puts it into a temporary holding area called the **Staging Area** (or Index). It’s like putting items into a shipping box, but you haven't taped it shut yet.

### 2. `git commit -m "Your message"` (The Local Repo)

* **What it means:** "Seal the box and lock it into my computer's vault."
* **What it does:** This takes everything you just placed in the Staging Area, seals the box, and assigns a permanent serial number (a commit hash) to it. It saves this snapshot to a hidden folder on your hard drive called `.git` (your **Local Repository**). Your progress is now officially saved on your computer, but **not** on the internet yet.

### 3. `git push origin main` (The Remote Repo)

* **What it means:** "Upload my locked boxes to the cloud."
* **What it does:** * `push` means upload.
* `origin` is the nickname Git gave to your specific GitHub website link when you typed that `git remote add` command earlier.
* `main` is the name of your branch.
* This command copies the locked snapshot from your computer's hidden vault and sends it over the internet to your **Remote Repository** on GitHub's servers.

#include <stdio.h>
#include <math.h> // Needed for pow() and sqrt()

#define ROWS 15
#define COLS 30

char canvas[ROWS][COLS];

// Function 1: Fill the canvas with underscores (Blank slate)
void initializeCanvas() {
    for (int i = 0; i < ROWS; i++) {
        for (int j = 0; j < COLS; j++) {
            canvas[i][j] = '_';
        }
    }
}

// Function 2: Print the 2D array to the terminal
void displayCanvas() {
    for (int i = 0; i < ROWS; i++) {
        for (int j = 0; j < COLS; j++) {
            printf("%c ", canvas[i][j]);
        }
        printf("\n");
    }
}

// Function 3: Draw a horizontal line
void drawLine(int r, int cs, int ce) {
    for (int j = cs; j <= ce; j++) {
        if (r >= 0 && r < ROWS && j >= 0 && j < COLS) {
            canvas[r][j] = '*';
        }
    }
}

// Function 4: Draw a rectangle
void drawRectangle(int sr, int sc, int w, int h) {
    int er = sr + h - 1; // end row
    int ec = sc + w - 1; // end col

    for (int i = sr; i <= er; i++) {
        for (int j = sc; j <= ec; j++) {
            if (i >= 0 && i < ROWS && j >= 0 && j < COLS) {
                // Only draw the outer frame edges
                if (i == sr || i == er || j == sc || j == ec) {
                    canvas[i][j] = '*';
                }
            }
        }
    }
}

// Function 5: Draw a Circle
void drawCircle(int cr, int cc, int rad) {
    for (int i = 0; i < ROWS; i++) {
        for (int j = 0; j < COLS; j++) {
            // Calculate distance squared from current spot (i, j) to center (cr, cc)
            double dist = pow(i - cr, 2) + pow(j - cc, 2);
            double radSq = pow(rad, 2);
            
            // Tolerance threshold of 1.5 keeps the text-line smooth
            if (fabs(dist - radSq) < 1.5) {
                if (i >= 0 && i < ROWS && j >= 0 && j < COLS) {
                    canvas[i][j] = '*';
                }
            }
        }
    }
}

// Function 6: Draw a Right-Angled Triangle
void drawTriangle(int sr, int sc, int h) {
    for (int i = 0; i < h; i++) {
        for (int j = 0; j <= i; j++) {
            int r = sr + i;
            int c = sc + j;
            
            if (r >= 0 && r < ROWS && c >= 0 && c < COLS) {
                // Only draw the outline edges
                if (i == h - 1 || j == 0 || j == i) {
                    canvas[r][c] = '*';
                }
            }
        }
    }
}

    printf("--- Day 3: 2D Graphics Editor (Short Variables) ---\n\n");
    
    initializeCanvas();
    
    // Draw all 4 shapes to test
    drawLine(1, 2, 10);
    drawRectangle(3, 2, 6, 4);
    drawCircle(7, 20, 4);
    drawTriangle(8, 2, 5); // Start row, start col, height
    
    displayCanvas();
    
    return 0;
}
